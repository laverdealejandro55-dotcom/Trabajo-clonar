01 / CONCEPTOS

¿Qué es GitHub?

GitHub es una plataforma que permite alojar proyectos, administrar código y trabajar en equipo utilizando Git.

01
⌘

Control de versiones

Git registra los cambios realizados en tu proyecto. Puedes consultar el historial y regresar a versiones anteriores cuando sea necesario.

02
◈

Trabajo colaborativo

Varias personas pueden trabajar en un mismo proyecto, crear ramas, realizar cambios y unir sus aportes.

03
◇

Proyectos públicos

Comparte tus proyectos con otros desarrolladores y participa en proyectos de código abierto.

02 / DIFERENCIAS

Git y GitHub

Aunque suelen mencionarse juntos, no son exactamente lo mismo.

GIT

Git

Es un sistema de control de versiones distribuido. Se utiliza principalmente desde la terminal para controlar los cambios de un proyecto.

  • Controla versiones
  • Funciona localmente
  • Permite crear ramas
  • Registra cambios
+
GH

GitHub

Es una plataforma online que utiliza Git para almacenar repositorios y facilitar la colaboración entre desarrolladores.

  • Aloja repositorios
  • Facilita la colaboración
  • Pull Requests
  • Issues y proyectos
03 / FUNCIONES

Todo lo que puedes hacer

GitHub ofrece muchas herramientas para organizar, desarrollar y compartir proyectos.

📁

Repositorios

Guarda todo el código y archivos relacionados con un proyecto en un mismo lugar.

🌿

Branches

Trabaja en nuevas funcionalidades sin modificar directamente la versión principal.

🔀

Pull Requests

Propón cambios y permite que otros miembros revisen tu código antes de integrarlo.

🐛

Issues

Registra errores, tareas, ideas y mejoras relacionadas con un proyecto.

👥

Equipos

Colabora con otros desarrolladores y organiza proyectos de manera profesional.

🚀

GitHub Actions

Automatiza tareas como pruebas, compilaciones y despliegues.

04 / TERMINAL

Comandos esenciales

Estos son algunos de los comandos que más utilizarás cuando comiences a trabajar con Git.

git init
Crea un nuevo repositorio Git.
git clone
Descarga un repositorio existente.
git status
Muestra el estado actual del proyecto.
git add .
Prepara los cambios para realizar un commit.
git commit
Guarda los cambios en el historial.
git push
Envía los cambios al repositorio remoto.
git pull
Descarga los últimos cambios del repositorio.
git branch
Permite consultar y administrar ramas.
